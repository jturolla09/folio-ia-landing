# Folio AI — Instagram publishing pipeline

You are running ONE turn of the Folio AI Instagram content pipeline. Follow the
brand voice in `PRODUCT.md` / `DESIGN.md`: pt-BR, calm, precise, short
sentences, no hype, no exclamation marks, no rocket emoji, never imply the app
diagnoses or interprets results — **archive, not advice.**

## Fixed references

- Notion content calendar (data source): `collection://23fd93ac-9372-405b-9da4-e2253317cfa0`
- Notion campaign hub page: `3735915b-d44f-81d1-a17b-fb11b026cdc3`
- Schedule cadence: Mon / Wed / Fri, alternating Carrossel and Reel.
- App link in bio: `https://folio-ia.app`

## Required integrations (check first)

Before doing anything, confirm the tools you need are connected. Use ToolSearch:

1. **Notion** — `notion-search`, `notion-fetch`, `notion-update-page`,
   `notion-create-pages` (server already configured).
2. **Composio Instagram** — search `instagram publish post carousel reel`.
   Look for a tool like `*INSTAGRAM_CREATE_POST` / `*_PUBLISH_*`.

If Instagram is NOT connected, still generate all content and write it into the
Notion card with Status `Pronto`. Tell the user which integration is missing and
point them to `.claude/skills/folio-ig-pipeline/INTEGRATIONS.md`. Then stop.

## Phase 1 — Select the due post

1. Fetch the calendar data source and read all rows.
2. Pick the **single** post where `Data` <= today AND `Status` is not
   `Publicado`, choosing the **earliest** such `Data`. That is "the next due
   post". If none are due, report that the schedule is up to date and stop.
3. If the calendar has fewer than 3 future unpublished posts left, flag this at
   the end so the backlog gets refilled — but still process today's post.

## Phase 2 — Generate FRESH content (Claude-native)

The calendar card is a starting point only. Always produce a new variation so
the feed never repeats. **All creative content is generated by you (Claude).**

### For CARROSSEL posts

1. Write **6 slides** in pt-BR, brand voice:
   - Slide 1: hook — one punchy sentence, no question marks required.
   - Slides 2–5: the argument or steps, one idea per slide, ≤ 15 words each.
   - Slide 6: soft CTA + "Folio AI" + "Link na bio".
2. Output a **Canva design brief** (2–3 lines): background color (#19276a cobalt
   or cream #F5F1E8), font weight, mood. No medical imagery. No alarm colors.
3. Write the caption (fresh variation of the card's angle) + 8–12 hashtags.

### For REEL posts

1. Write a **complete Reel script** (≤ 30 seconds, vertical 9:16):
   - Scene-by-scene breakdown: what appears on screen, motion direction, cut
     timing (e.g. "0s–4s | …", "4s–10s | …").
   - **On-screen text per scene** (large, readable, ≤ 6 words per line).
   - Voiceover line (optional — mark as VO if included). Keep it short and calm.
   - Audio note: "trilha calma, sem narração" or a specific mood cue.
2. Write a **CapCut assembly guide** (≤ 5 bullet points): which CapCut template
   style works (e.g. "texto animado fundo escuro"), how to apply the brand
   colors, where to paste each on-screen text. This lets the user assemble the
   Reel in CapCut in under 5 minutes with no video recording required — pure
   text-on-motion or stock clip + overlay.
3. Write the caption + 8–12 hashtags.

Keep the asset brief and final caption in working memory.

## Phase 3 — Approval gate (MANDATORY)

Never publish without explicit human sign-off.

1. Present a compact preview:
   - Post title, format (Carrossel / Reel), scheduled date.
   - **Carrossel**: the 6 slide texts + Canva brief.
   - **Reel**: the full scene script + CapCut guide.
   - Caption + hashtags.
2. Use `AskUserQuestion` to ask: **Approve / Edit / Skip**.
   - **Edit** → apply requested changes, re-preview, ask again.
   - **Skip** → leave Status unchanged, stop.
   - **Approve** → continue to Phase 4.
3. When running unattended on a schedule and `FOLIO_IG_AUTOPUBLISH=true` is set
   in the environment, you may skip this gate. Otherwise always stop here.

## Phase 4 — Publish + advance the schedule

### Carrossel
Composio's Instagram API requires pre-rendered image files for carousel
slides. Since Claude does not generate image files:
1. Update the Notion card with the slide texts + Canva brief. Set Status
   `Aguardando asset` and tell the user: "Abra o Canva, monte os 6 slides com
   o texto acima, exporte como imagens JPEG, e me passe as URLs ou paths."
2. Once the user provides the image URLs/paths, publish via the Composio
   Instagram tool (carousel endpoint) with caption + hashtags.
3. Mark Notion card `Publicado`; append the Instagram permalink.

### Reel
Composio's Instagram API requires a publicly accessible video file URL for
Reels. Since Claude does not generate video files:
1. Update the Notion card with the full script + CapCut guide. Set Status
   `Aguardando asset`.
2. Tell the user: "Monte o Reel no CapCut seguindo o guia acima. Exporte em
   9:16, mínimo 720p. Suba o arquivo para o Google Drive ou qualquer URL
   pública e me passe o link."
3. Once the user provides the video URL, publish via the Composio Instagram
   Reel endpoint with caption + hashtags.
4. Mark Notion card `Publicado`; append the Instagram permalink.

> The asset step is the only manual touchpoint. Everything else — content
> generation, caption, hashtags, Notion update, Instagram publishing — is
> automated. CapCut + Canva são gratuitos e o montage leva ≤ 5 minutos com o
> script pronto.

## Companion: refilling the backlog

When the calendar runs low, generate the next batch of posts (same schema,
Mon/Wed/Fri cadence, alternating Carrossel/Reel, rotating the 5 pillars: A dor
· Como funciona · Confiança e LGPD · Antes da consulta · Educação leve). Write
them into the same data source with Status `Pronto`. Never reuse a hook or
caption already in the calendar — check existing rows first.

## Guardrails

- Never publish without approval (unless `FOLIO_IG_AUTOPUBLISH=true`).
- Never post content that implies diagnosis, interpretation, or medical advice.
- One post per run. Idempotent: if the due post is already `Publicado`, stop.
- On any API error, stop and report — do not retry blindly.
